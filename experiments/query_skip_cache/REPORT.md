# 相似query的学习式skip决定缓存

缓存源是1000条历史query的真实模型skip记录。当前query寻找最近历史query，同一节点有skip标记且相似度达标才复用；未命中继续模型评分。Guard额外检查rank及展开进度。缓存近邻查找和成员查表均计入总延迟。模型版本、阈值、L、beam和BFS缓存固定；详见PROTOCOL.md。

主策略在验证集按最低总平均延迟选择，约束相对Fresh Recall损失<=0.1个百分点，允许回退。所有测试阈值诊断公开，但不用于重选。
