# 学习式剪枝决定的相似查询缓存

检验：当前查询与已缓存查询足够相近、且遇到同一节点时，能否复用过去模型的skip决定，省掉当前特征提取与推理。它仍以原学习式策略为基础，不是全局节点黑名单，也不是恢复/延迟展开；本次搜索的skip依然会略过该候选。

数据：SIFT1M、DEEP1M，各自使用io_predictability已有1000条训练查询作为已完成的历史查询缓存；自然验证/测试各1000条，query ID互斥。缓存只从历史查询的实际模型搜索中生成，缓存生成不读GT、不做Oracle标记。验证与测试不写回缓存，不跨模型/阈值复用。固定L=100/beam4/K10/BFS cache10000，缓存命中候选始终保留，不使用ET/reorder。

模型：原17维state_lr（既有验证unsafe_fpr_0.005阈值）；Top3三特征MLP（既有fnr_0.5pct阈值）。两者分别建立缓存、分别比较。MLP检验推理较贵时的潜在收益；不据本轮测试换阈值。

存储：全局排序唯一节点ID池只保存一份节点身份；每条缓存query存排序记录(pool_index:uint32, candidate_rank:uint32, completed_expansions:uint32)。pool_index作为4字节共享引用，不用8字节裸指针。节点池不保存向量或邻接表，它们属于原索引。逐query skip成员关系与状态是上下文信息，不能因同一节点出现而合并掉。报告节点去重比、所有成员关系引用数、原始ID列表字节、共享池/成员关系/状态/缓存query向量/offset/范数的各自字节；仅去重4字节ID未必省内存。

查找：每次新query用精确全缓存向量搜索找最近历史query，计时包含SGEMV、距离复核、相似度判断、成员查表。相似度rho=||q-q_cached||²/max(||q||²,||q_cached||²,1e-12)，只在rho<=阈值时激活复用。阈值网格{0,0.0001,0.001,0.01,0.05,0.1,0.25}，自然查询低命中也如实报告。节点查询是全局ID池二分+query记录二分，不运行模型；无命中时用原模型当前路径状态评分。受保护的cached节点不参与skip复用。

策略：Fresh（原模型，无query缓存查找）；LookupOnly（完整近邻/成员查找但仍全部重新评分，用于隔离缓存维护代价）；Reuse（缓存skip直接复用）；GuardedReuse（还要求候选rank完全相同、已完成展开数差<=4）。状态检查只用读取前元数据。真正复用在17维特征构建/模型评分之前发生，保持消费beam槽位的语义。

控制场景：从历史query随机取互不重叠的100个父query作相似验证、另100个作相似测试，各生成相对L2幅度1%与5%的高斯扰动，共200/200条；seed=20261017。扰动后的向量重新对全部1M base做float64分块精确top10计算，不复用父query GT。父query在缓存中是刻意构造的高命中场景，不冒称自然独立查询。另取50个历史query原样重复，仅作精确复用结果一致性与收益上限检查，不能将该场景推广到一般查询，也未将最终结果缓存作为本轮性能对照。

评价：自然/相似两个workload独立在验证集选参数，目标为最小总平均延迟，约束相对Fresh平均Recall损失<=0.1个百分点，允许Fresh回退；缓存查找耗时必须包含。验证2轮，锁定所选策略后测试3轮；所有冻结阈值的测试诊断都公开，不用于重选。每轮配置随机顺序、串行执行，内部4线程。模型/索引/历史缓存构建不在请求计时内。报告Recall@10、相对Fresh受损queries、reads/q、model_calls/q、模型调用减少率、query缓存命中率、复用候选数、总延迟/lookup延迟/p95/QPS、缓存内存。模型调用统计不含cached候选的直接保留。

额外审计：在复用策略的真实轨迹上，命中的skip仍额外计算一次原模型新分数，但保持复用skip行为不变；统计与新评分的冲突。审计运行不用于计时，也不宣称冲突等于质量下降。精确重复、rho=0无命中的自然查询、LookupOnly应与Fresh的ID/距离/读取完全一致。报告提交SSD读取请求，不等于physical SSD I/O。
