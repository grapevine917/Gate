# 同Recall：全局一次标记、LR pruning、LR+Reuse

只比较三种方法，模型与历史数据不变：全局一次标记（n>=1且z=n）、既有17维LR、同一LR加query级skip复用。原始DiskANN为参照。固定L100/beam4/K10/4线程/BFS cache10000。自然query独立验证/测试各1000；高相似query验证/测试各200，复用之前1%/5%扰动及独立全库GT。

全局标记保留原始完整标记表 f=1。为获得可调Recall，使用seed=20261017的固定SplitMix64节点哈希，只启用原标记节点中hash比例<f的部分。同一个node跨query选择一致，不根据GT挑节点，不改变低贡献判据；f=1须与原表字节一致，f=0为空表。它是原方案的启用比例版本，不能把f<1称为原完整标记表。

LR保持原权重，调整retain阈值tau。LR+Reuse固定query相似度rho<=0.01、不自动回退，不使用额外guard；每个tau用相同1000历史训练query重新跑真实LR，生成该tau独立skip缓存，不允许跨阈值复用旧skip。缓存构建不使用GT。测试不写回。

粗网格：f={0,.05,.1,.2,.4,.6,.8,1}; tau={0,.005,.01,.02,.04,.06,.08,.1,.15,.2,.3,.5,.8,1}，加既有tau。验证一次扫描质量/请求（确定性，不靠单轮延迟挑选）。对每workload，Recall损失预算0.5/1/2pp分别设置共同可达目标：原始验证Recall减去min(预算,完整全局标记的验证损失)。若完整标记本身损失不到2pp，不强迫它额外损失召回。测试会报告实际目标，不把“同预算”冒充“同Recall”。

验证细化：每种方法、每个目标，最多8轮在已有Recall跨越目标的相邻参数间取中点，向目标对齐；LR出现新tau时同时测LR与Reuse并生成独立缓存。允许轻微非单调，保留全部点，不声称全局最优。目标匹配窗口为[target,target+0.05pp]，选择窗口内请求最少点；若无匹配点，只选最近的更高Recall点并明确记录偏差，不伪称对齐。

所有有限配置与细化点在测试前锁定。测试对粗网格和验证细化点统一测三轮，每轮随机顺序串行配置；单配置内部4线程。原始DiskANN预热，模型/索引/历史缓存构建排除在请求时间外，在线路由/查表/特征提取/评分全部计入。每workload用同一native计时框架。

报告分为两类：
1. 验证集选出的真实单配置，在测试集的实际Recall/请求/延迟及匹配偏差，测试绝不重选上线配置。
2. 描述性的同测试Recall曲线比较：在全部预先锁定的实测点之间线性插值，以请求最小的插值组合比较三种方法。实际目标=测试DiskANN Recall-min(预算,完整标记实际测试损失)，仅在各方法实测Recall范围共同覆盖时报告。插值请求/调用/平均延迟为估计，不是假装测得的单配置；不插值p95/QPS，不把测试曲线最优点当验证选中参数。所有原始点公开。

线性插值不要求Recall随tau/f全局单调；枚举跨越目标的点对构造最小期望请求，等价于描述性的query级随机混合期望，未部署或实测混合流量。与原完整一次标记直接对齐的固定锚点也单独报告，避免启用比例的定义变化被隐藏。

验证：训练/验证/测试自然query ID互斥；相似验证/测试父query互斥；所有模型/位图/缓存哈希锁定；f=1等于原表；tau分开的bank；三轮输出字节一致及reads/calls确定；原始完整Mark/DiskANN/旧tau LR的结果与旧实验一致。读取是提交SSD请求，不等于物理读盘。此前已观察过测试划分，不宣称全新未见数据。
