# P0-A：增加真实在线 Skip 复用

固定原始 P0-A 模型、阈值、索引、查询、L100/Beam4/四线程/10000节点缓存。历史仅来自互斥训练查询。所有方法本轮同一程序重新计时，在线查找、成员检查、推理和I/O均计入。

验证集 Recall 下限 99.550%；QPS 选中 `Guard_1`，P95 选中 `Guard_0`。测试集不参与选择。

9轮中位数及范围：

- Vanilla: P95 7.294–7.568 ms；QPS 561.5–594.4。
- Heuristic: P95 6.542–6.773 ms；QPS 627.4–654.1。
- MLP: P95 7.285–7.609 ms；QPS 646.0–678.7。
- Guard_1: P95 7.327–7.474 ms；QPS 649.7–693.8。
- Guard_0: P95 7.189–7.524 ms；QPS 650.2–705.2。

复用：在1000条历史查询中在线寻找欧氏距离最近者，以归一化平方距离 rho 过滤；历史同节点 Skip 才跳过模型及读盘。Guard 另要求相同候选rank、展开进度差不超过4。命中静态节点缓存始终保护。

所有重复均逐ID和离散计数一致；原三方法ID及BFS缓存与原P0-A完全一致；reader请求数与逐query一致，reader直接读字节按实际请求长度累计；当前环境无 /proc/self/io，无法核验块层 read_bytes。

自然查询历史重叠可能很低；查找成本可能抵消省模型收益。不能保证复用优于启发式。有限验证选参、既有测试集和主机噪声限制结论；重复范围重叠时不声称稳定加速。本次读取量为reader直接读请求字节，不声称已测得块层或SSD NAND流量。
