# SIFT1M：P0-A / P0-B 旧模型复测

使用各数据集已有同批混合L样本训练的 LR、XGBoost、17维状态MLP及对应ET，全部为旧代理标签权重，不重新训练，不使用风险监督模型或动态阈值。相同数据集共享索引、查询、K10、Beam4、4查询线程、10000节点BFS缓存。float1M和uint8 100M实现不同，跨数据集不是单纯规模消融。

计时包括现场状态提取、模型推理、搜索和IO；排除索引/模型加载、缓存构建、固定128-query热身、GT评分及输出。物理字节来自计时窗口Linux read_bytes，并严格等于实际Reader字节和逐查询读取数×4096；无交换。对照不按模型版本重复测量，相同配置/重复编号只保留一份。

## P0-B：独立调 L 和阈值

每方法64个预声明配置：原生64个不同L；其余8个L×8档参数。模型覆盖L=[15, 20, 30, 50, 75, 100, 160, 300]，原生包含全部这些L。三个Ours及三个ET+Ours版本共享原生、启发式、ET，合计576个唯一配置。Gate阈值为同一验证L100缓存未命中retain正样本的8档FNR，ET阈值和8个联合参数对在PROTOCOL.json中完整公开。联合组不是无限笛卡尔积搜索。

全部验证配置完成后，按每个Recall下限和三个指标分别选参并锁定，再测试。固定全测试网格的非支配前沿属于描述性结果，不能冒充未见测试集选参。曲线中每个点对应一个真实配置；连线仅帮助阅读，不产生插值测量。每项指标独立求前沿，避免把字节最优的配置重复当成P95/QPS最优。最终显示前沿及验证锁定点至少3次计时中位数，P0-A配置15次；均核对输出和计数重复一致。

## 核验

原权重、查询和程序哈希保持不变；原生关闭剪枝与历史结果一致，联合关闭ET与Gate一致；全部正式记录通过Reader/Linux物理IO一致性及无换页检查。IO异常尝试归档重测 1 次；测试唯一测量 1562 条。返回ID合法/唯一/尾部占位检查、GT重算Recall、重复离散计数检查均通过。不足K个返回结果按未命中计算，分母仍为10000。

限制：同一训练种子、有限参数预算、已观察过的基准查询，未含重训练不确定性；ET基于未剪枝轨迹训练，联合策略存在分布变化。实测Recall不同的配置不能声称严格同质量优势。物理字节为WSL客户机块层读取，不是SSD内部NAND遥测。
