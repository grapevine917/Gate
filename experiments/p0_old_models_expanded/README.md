# 扩大调参范围的旧模型主实验补充

范围：SIFT1M、DEEP1M、SIFT100M，九个方法族。沿用原实验的匹配混合L训练旧权重，固定索引、查询、K10、Beam4、4线程、10000缓存节点，不重新训练，不改动态阈值。旧实验与旧模型均不覆盖。

## 主实验：验证集选参

每族192个唯一配置：原64+96新粗搜+32验证局部细化。原生192个不同L；其余各族使用相同配置数量，但有效搜索维度不同，不能解释为各方法获得同等穷尽度。1M L范围10–1600，100M范围10–4000。启发式同时改变rank/exp；联合组同时改变L/Gate阈值/ET阈值。

验证Recall下限95/98/99/99.5/99.8/99.9%，按P95最小、QPS最大、物理字节最小分别选择真实配置。局部搜索只使用验证数据。在新测试网格运行前保存 `VALIDATION_SELECTION_LOCK.json`。锁定配置九轮复测，测试集是否达标独立报告。查询曾在此前实验观察过，不能宣称全新未见查询盲测。

全192配置测试网格的三项性能前沿是描述性结果，指标各自独立求前沿；最终显示前沿点至少三次复测。曲线连接只引导阅读，不代表插值测量。P0-A不重跑，继续引用原已完成结果。

## 严格Recall描述性补充

从原生测试结果中选离98/99.5/99.8%最近的实际命中数作锚点，必须距名义目标不超过0.15个百分点，否则报告目标不可用。锚点不用绑定L100。九族以相同整数命中数比较；这是同一已观察查询上的描述性匹配，不是验证锁定盲测。

每个非原生方法每目标最多72次额外探测，扩展六个L/参数分支，各两端点及最多十次二分。启发式改变扩展门槛；联合组前三分支改变Gate阈值/不同ET，后三分支改变ET阈值/不同Gate，避免固定单一ET。所有分支继续评估，不在首个精确命中时停止，以便三指标各自选择。Recall可能非单调，搜索仍非穷尽。原生锚点由主网格确定。

各指标分别在严格匹配且实际剪枝/终止生效的候选中选优，然后冻结，在独立的11–19重复编号交错复测九轮。联合组要求Gate与ET均生效。无精确匹配则显示最近候选及命中差，不冒充严格对齐，也不保证所有九组都会对齐。原生不需要72次阈值探测，因为锚点本身就是原生已测点。

## 运行与产物

后台入口：`.venv/bin/python experiments/p0_old_models_expanded/launch.py`。支持断点续跑，有进程检查与文件锁。不要并发第二份任务。各数据集串行运行，避免争抢SSD计时。继续继承原runner返回ID/GT重算、Reader/Linux字节一致及无swap检查。

进度看根 `STATUS.json` 和 `pipeline.log`，各数据集 `PRIMARY_COMPLETE.json` / `strict_progress.json` / `repeat_status.json`；失败看 `FAILED.json`。`BACKGROUND_STATE.json`仅记录启动PID，不是实时心跳。根 `COMPLETE.json` 才表示整轮完成。

结果分开保存：`validation_selected_test.csv`、`primary_configurations.csv`、`strict_results.csv`、`all_strict_candidates.csv`；每行保留具体L和全部阈值、Recall/P50/P95/P99/均值/QPS/字节/读取/扩展/模型调用等指标。最终汇总 `REPORT.md`，三指标性能图 `figures/`，PNG/SVG/PDF共九个文件。
