# DEEP1M P0-B

同一DEEP1M原图R64/Lbuild100/PQ34、K10、Beam4、10,000节点缓存、4查询线程/MKL单线程；验证/测试各1000条互斥查询。模型仅用DEEP训练查询拟合。

## 实验范围

每方法64个预先锁定配置：Tuned DiskANN扫描64个L；其余8个L×8档参数。所有Gate按验证L100全候选的相同retain-FNR预算标定，缓存命中保护；不保证最终Recall。与SIFT原P0-C的训练分数量化阈值有所不同。
验证集分别按质量目标和P95/QPS/读取量选参，在测试前锁定。完整固定测试网格的前沿属于描述性结果，不能用测试挑出的点声称无偏部署收益。最终各指标前沿、精确同Recall赢家、质量要求下赢家和验证锁定点均重复3次，时间取中位数。

## 验证与解释边界

所有Recall由返回ID与对应DEEP GT复算；直接读请求和实际reader字节与Linux read_bytes核对；最终重复ID、读取、展开、skip和停止计数一致。P0-A baseline与本实验L100 baseline完整ID一致。
时间包含特征抽取、模型推理、I/O及搜索，排除加载、缓存构建、128条热身、GT与输出。QPS=1000/四线程正式搜索墙钟时间；P95为单轮1000查询P95的跨次中位数。重复范围见all_configurations.csv。
I/O是WSL2客户机块层流量，不是唯一扇区数或SSD内部NAND计数。DEEP查询曾在历史实验中观察，属于探索性实验。模型、索引和查询hash均锁定。
与SIFT原P0系列相比，本次神经网络检查160轮且逐步降学习率，阈值预算也做了DEEP标定；跨数据集变化不能纯归因于数据集难度。ET仅训练于未剪枝路径，联合组可能存在轨迹偏移；8阈值对也不足以排除更充分搜索的收益。
分类误差、模型推理成本、最终检索质量是不同量。有限网格和重复计时不构成普遍优越性或统计显著性证明。
共享的完全相同对照配置只测一次供多个P0实验引用；P0-A两个版本独立计时。完整记录在父目录runs/、all_test_runs.json和INPUT_LOCK.json。
