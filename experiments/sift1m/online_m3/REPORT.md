# M3 online L=100 sweep

阈值来自 validation；每次候选选择时用当前在线 state、q/v 和交互项实时推理，在读盘前决定是否跳过，保留原 beam slot。没有复用 baseline 的跳过掩码。
v 全表常驻 RAM（512 MB）；gate 特征构造和推理计入 Latency/QPS，模型/向量加载不计入。SSD Reads 是索引发出的读请求数。
固定 K=10、L=100、beam=4、threads=4、cache=10000；各配置随机顺序重复三次，报告中位数。计时是预热后的当前主机结果，不是冷盘实验。

FNR target 是离线验证标签的阈值校准目标，不是在线召回损失保证。在线轨迹改变后，state 分布和候选集合也会改变。
tau=0 全量搜索逐项复现历史结果；q0 的在线 pre_io_state 与离线完全一致，C++/Python 概率误差记录在 verification.json。
每次搜索的命令、日志、结果 ID/距离和逐 query 统计均保留。重现：`.venv/bin/python experiments/sift1m/run_online_m3.py`。

## Interpretation

在本次单机预热测量中，低阈值减少 I/O 后不一定加速；gate 推理有成本。全量 1%/2% 档 QPS 相对 baseline 提升约 6.1%/13.6%，Recall@10 分别下降 0.069/0.149 个百分点。
held-out test 上，1%/2% 档 QPS 提升约 6.0%/12.9%，Recall@10 分别下降 0.040/0.170 个百分点。
三轮结果 ID 一致；统计计数及 Recall 从结果 ID 的独立重算通过。见 verification.json、deltas.json 和 analysis.log。
