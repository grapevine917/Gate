LGTRACE1 (8 bytes), then per-query uint32 header [query,L,visited,nexp,nedge], nexp records [node,degree,fresh,admitted,exact_float32,cached] (24 bytes), nedge records [parent,child,pq_float32,flags] (16 bytes). Native little-endian. flags: fresh=1, admitted=2. Records retain search processing order; blocks may have arbitrary query order. Only unfiltered float L2, no disk PQ/reorder is used in this experiment. Expansion is adjacency processing, visited includes medoid and every distinct neighbor. useful=admitted>0. Skipping a neighborhood retains exact scoring of its parent node.
