# 真实查询流量回放协议

状态：等待真实查询流输入。当前已检查项目 data、已有实验和 trace 目录，未确认任何生产请求流；SIFT/DEEP 基准查询及人工扰动不得标为真实流量。本文是待执行协议，不是实验结果。

## 输入与溯源

必需：查询向量、原始请求顺序、对应的 base/index 和距离度量。若需评估到达负载与排队，则另需时间戳（含单位）；会话或租户字段可选。记录输入 SHA256、向量维度、请求数、时间范围和数据来源。相同向量的真实重复请求保留；不可重排或人为添加相似查询。

真实流量的向量空间必须与索引及模型兼容。若不是原 SIFT/DEEP 空间，需要对应索引，并仅使用早期训练区间重训模型及构建标记，不能直接迁移既有权重后宣称公平比较。

## 比较方法

原始 DiskANN；原始完整全局一次标记；LR pruning；LR＋相似 query 的 skip 复用。另列按固定节点哈希部分启用标记的变体以补全召回曲线，不能与原完整方案混称。旧 Top3/Joint 等基线仅在数据空间和模型适用时加入。

全局一次标记保持原定义：历史 miss 候选至少出现一次，且所有已观测事件均为低贡献（admitted=0 且不在该查询最终 top10）才标记。原完整方案在评估段冻结。持续更新的全局标记如需测试，作为独立变体，避免改变原方案定义。

LR＋复用分列固定历史库控制组和滚动库实验组。滚动库只可见此前完成的请求；未命中仍执行 LR。不得把本次查询或未来请求先放入库。默认沿用 rho<=0.01，记录模型版本和阈值；缓存中的决定必须来自同一版本/阈值。复用命中不当作重新独立预测的证据。更新策略、容量、共享节点引用、淘汰策略须在验证段确定并锁定；满库淘汰必须释放引用，报告实际内存。

## 时间划分与参数

按时间先后划分训练/验证/测试，初始拟定20%/20%/60%，数据量不足则在执行前调整并记录。允许真实重复请求跨时间段出现，禁止未来信息泄漏。测试前锁定参数，测试期间不使用 GT 调参或更新。

验证段扫描参数并按0.5/1/2pp召回损失预算选择最低请求方案。完整标记不满足预算时如实报告，另报部分启用变体。测试如实展示实际 Recall，不声称验证对齐即测试对齐。预锁定曲线的同 Recall 插值另列为估计，不能代替真实配置结果。

GT用于独立质量评估；训练标记所需最终top10取原搜索返回结果，不能偷用精确GT。精确GT缺失时，对同一固定样本计算精确近邻，报告抽样方法及不确定性，不能以与DiskANN输出一致代替真实Recall。

## 回放与指标

所有方法使用同一请求流、索引、搜索参数、硬件、并发与内存预算口径。分别报告冷启动和预热后阶段，至少三轮，方法执行顺序随机。每轮重置各方法状态并重放同一前缀；不在每条请求后重置缓存。

没有时间戳时只称按原序回放，报告服务时间与吞吐，不能宣称生产排队延迟。顺序状态基准先以单请求执行保证因果；有时间戳时再按原到达过程与固定并发实现开放式回放，查询只能读取此前已提交的缓存状态，明确是否计入排队及过载行为。

逐请求保存Recall@10、提交读取请求数、展开数、模型调用、复用候选数、匹配耗时、搜索耗时、更新与淘汰耗时、端到端耗时和缓存内存。总表报告平均值、p50/p95/p99、QPS、超时/失败率，并按时间窗口观察漂移与召回下降尾部。读取请求计数不能冒称物理SSD I/O；物理I/O若可测另列。

用真实流统计精确重复率、历史最近query距离分布、rho命中率和复用记录命中率，不人为设置重复比例。比较完整维护开销后的净收益，内存除共同DiskANN缓存外另列增量，并补充相同总内存预算比较。

## 正确性检查

禁用标记/零LR阈值与DiskANN结果一致；空复用库与新预测结果一致；缓存版本/阈值一致；逐请求记录缓存项插入完成时间且早于当前请求读取时间；训练/验证/测试边界和参数锁定有记录；多轮结果差异若由并发提交次序引起需报告，不能假设确定性。
