# 延长训练对照实验

## 训练是否充分

固定原有数据和17–128–64–1结构，每个任务3个种子、160轮，40轮后逐步降低学习率。只用训练内部200条查询选种子与轮次，再用1200条训练查询重新拟合。

|模型|原选定轮次|新选定轮次|新内部损失|同种子前40轮最佳损失|损失降低|
|---|---:|---:|---:|---:|---:|
|gate|23|137|0.3510461|0.3516555|0.17%|
|et_unpruned|38|120|0.0049587|0.0050968|2.71%|
|et_adapted|20|135|0.0040380|0.0040543|0.40%|

不同任务损失定义不同：Gate为BCE，ET为Recall MSE，不可横向比较。延长训练同时改变学习率，收益不能纯归因于增加轮次。种子与轮次选择带来的不确定性不包含在单个最佳损失中。

## 范围与复现

- 原模型、原实验均保留；本轮独立计时，不能与历史绝对时间直接比较。
- LR紧容差检查见LR_CONVERGENCE.json；增加优化迭代不等于增加模型容量。
- 新MLP Gate是mixed-L贡献代理标签训练，与原P0-A的L100模型不同。
- ET_old为历史未剪枝ET；ET_new为本次同数据延长训练ET。Joint_LR_old为上一轮剪枝轨迹适配ET；Joint_LR_new为其延长训练版。
- 新MLP Gate没有与LR轨迹训练的ET拼接，避免引入新的轨迹不匹配。
- 标签、查询数量与特征未增加；较低预测误差不保证更好的最终Recall/成本交换。
- 所有目标及P95/QPS独立选参结果见validation_locked_test.csv；重复范围见test_summary.csv。
- 训练与验证/测试按查询隔离；当前基准查询曾被观察，属于探索性实验。
- 包源未提供Matplotlib，保留完整训练曲线JSON与结果CSV。
- 复现：bash experiments/training_extension/run.sh。
