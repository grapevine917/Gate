# SIFT100M：L=100 训练模型的温和动态策略验证

MLP 复用已有 SIFT100M 纯 L=100 权重；LR 使用同一批 SIFT100M L=100 训练样本补训，未使用旧的混合 L LR。SIFT100M，K=10，验证/测试各 1000 查询；主实验推理 L=100、4 搜索线程、beam=4、缓存 10000 节点。168 个唯一参数配置在测试前冻结。

## 策略与主实验

早期阈值严格等于对应静态模型阈值；仅当候选 rank > r 且已完成扩展数 > e 时，阈值提高至 multiplier × 静态阈值。模型分数低于当前阈值时剪枝；缓存命中节点受保护。触发条件及 multiplier 是人工设计并通过验证集选取，模型权重不变。

主实验先要求验证 Recall 不低于静态组，再在实际有额外剪枝的候选中选择验证 P95 最低者；若无合格候选，报告质量条件未满足。以下选择在测试前锁定：

## 校验与限制

本轮完整搜索 100,000,000 条 128 维 uint8 向量的原 SIFT100M 索引（R=64、build L=100、PQ=34 bytes）。与 SIFT1M 的 float 索引及独立模型相比，跨数据集差异不能单独归因于数据量。两模型都是17维状态模型，本轮不加载 q–v 压缩向量表。
晚期 Extra skips 指动态搜索轨迹中，当前基础阈值会保留、提高阈值后被跳过的候选；不是离线可加总的独立节点因果收益。每次搜索重新初始化查询状态，各配置共享的只有只读索引和缓存。
原始 ID 重算 Recall；每次 reader_requests×4096、reader_bytes 和 Linux read_bytes 严格相等；无交换；输出 ID、IO 和扩展计数在重复间一致；阈值不变的动态 identity 配置与静态输出完全相同。源模型、输入数据和原生程序的 SHA256 保持不变。物理 IO 不一致的尝试归档于 rejected_io，并重试，不混入统计。
本轮 IO 计数不一致归档次数：0。

同 Recall 仅指总命中率相同，不保证成功的是同一批查询。只有一个已训练模型种子，有限且不均匀的参数网格；验证集各配置只扫描一轮，选参可能受计时波动影响；最终重复计时不能替代重训练不确定性，也不构成收益显著性的检验。该查询拆分此前已被检查，本实验属于探索性验证。全量指标保存在 CSV，原始逐查询数据与协议保留在本目录。

## 复现

项目根目录依次运行：

```bash
.venv/bin/python experiments/sift100m_mild_dynamic_recall_aligned/prepare_validate.py
.venv/bin/python experiments/sift100m_mild_dynamic_recall_aligned/evaluate_test.py
.venv/bin/python experiments/sift100m_mild_dynamic_recall_aligned/report.py
```

脚本保留已通过严格检查的原始测量，重复执行会复用本目录结果；需要全新计时应使用另一个实验目录，并重新冻结协议。
