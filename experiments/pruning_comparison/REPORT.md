# DiskANN / LR / Top3 / 联合剪枝对照实验

训练、验证、测试 query ID 互不相交。现有模型冻结；所有 L、beam、阈值组合只在验证集扫描。分别按 SSD 请求数与平均延迟最小化选参，约束验证集绝对 Recall@10 ≥ 99%、99.5%、99.7%。未达到约束时标为无可行配置。测试结果不用于重选，未达测试召回目标的结果仍如实展示。

每个数据集 240 组配置，验证两轮、冻结后测试三轮，随机顺序串行运行。延迟和 QPS 报告中位数；缓存预热，4 线程、10000 节点缓存、K=10。LR 为 state_lr；Top3 为 rank、completed_expansions、visited_count 三特征 MLP。Joint 为任一模型判定 skip 就剪枝；包含两个模型的真实推理耗时。SSD 指提交的读取请求，不能等同物理读盘次数。
